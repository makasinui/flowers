# Для тебя 🌷

Небольшой сайт для выбора понравившихся цветов. Без бэкенда, установки и сборки.

1. Положи фотографии в папку `img`: `1.jpg`, `2.jpg`, …, `8.jpg`.
2. Открой `index.html` в браузере.

Поддерживаются также `.jpeg`, `.png`, `.webp`, `.avif` и расширения `.JPG`, `.JPEG`, `.PNG`, `.WEBP`. Если у одного номера есть несколько файлов, приоритет у JPG. После замены фотографий обнови страницу. Лучше использовать вертикальные снимки: карточки обрезают фото до пропорций 4:5.

Пока фото нет, отображается иллюстрация-заглушка. Названия нейтральные («Цветы №1»), чтобы можно было загрузить любые цветы.

Для 6 или 7 вариантов сократи массив `FLOWERS` в начале `script.js`, например: `[1, 2, 3, 4, 5, 6]`.

Сердечки сохраняются в текущем браузере через localStorage, если браузер разрешает его использовать. Вкладка «Мне нравятся» показывает избранное. Кнопка «Поделиться выбором» копирует номера в буфер обмена; если буфер недоступен, появляется окно с текстом для ручного копирования. Автоматической отправки нет.

Чтобы девушка открыла сайт на своём устройстве, отправь ей всю папку с фотографиями или размести её на любом статическом хостинге. Одна ссылка на локальный файл на твоём компьютере на другом устройстве не откроется. Выбор между устройствами не синхронизируется — его можно отправить кнопкой копирования.

Шрифты загружаются из Google Fonts. Без интернета сайт работает с системными шрифтами.
